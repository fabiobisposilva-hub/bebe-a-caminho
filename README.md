# BeBê a CaMinHo

O diário da Maria, da barriga em diante: diário, fotos e álbuns com a data certa, pré-natal com leitura de laudos,
histórias do mês e do ano, e o bom dia das 9h para a mamãe.

- **No ar:** https://bebe-a-caminho.pages.dev
- **Feito com:** HTML/JS num arquivo só (`app/index.html`), Supabase (banco, login, fotos, função do bom dia) e Cloudflare Pages (site).
- **Desenvolvido por:** Fabio Bispo, 2026.

## Comandos

```bash
npm install
npm test
```

As instruções para o Claude estão em `CLAUDE.md`. O histórico e as decisões estão em `docs/CONTEXTO.md`.
O passo a passo para usar o projeto no Claude Code está em `docs/PASSO-A-PASSO.md`.
